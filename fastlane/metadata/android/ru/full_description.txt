Gesture Drawing Practice — приложение с открытым исходным кодом для художников. Оно показывает выбранные вами изображения из галереи, каждое в течение заданного времени (например, 1 минуты). Есть возможность отображения таймера обратного отсчёта и паузы (чёрного экрана) между изображениями.

<b>Функции</b>

* 🤖 выбор нескольких изображений с сохранением порядка;
* ⏲️ четыре стандартных варианта длительности показа для практики;
* 😴 четыре варианта длительности паузы между изображениями;
* 🎨 настройки внешнего вида и отображения таймера обратного отсчёта.

<b>Использование</b>

1. Нажмите большую красную кнопку.
2. Выберите изображения из галереи.
3. Измените настройки или оставьте по умолчанию.
4. Нажмите «Start Session».
